cost-accountant

18,280 API requests, 4.61 billion tokens, $6,110.01. Priced by token class, reconciled two independent ways, and honest about the part that cannot be attributed to any artifact.

A per-artifact cost and latency accountant for AI pipelines. It reads real usage out of Claude Code transcripts, prices each token class at its own rate, attributes the spend to the files that were produced, and emits a receipt per artifact. Source on GitHub.

Three things the numbers say

94.9% of the tokens are cache reads. Adding input_tokens, cache_read_input_tokens and cache_creation_input_tokens into one figure and multiplying by the input rate gives $27,443.79 for this corpus, 4.5 times the real $6,110.01. That is not a rounding difference; it is the whole answer. Both numbers are in data/ledger.corpus.json, per model, so this comparison can be checked rather than taken on trust.

A streamed turn writes its usage on every line. The corpus has 18,280 distinct API requests spread across more usage-bearing lines than that, each repeating the full usage object. Summing over lines roughly doubles the bill. The extractor deduplicates by requestId.

Only 8.2% of the money lands on a file. 2,569 of 18,280 requests wrote or edited anything; the rest read, searched, ran commands and thought. That overhead is real and it is most of the bill, so the per-artifact figures on this page show it amortised across the artifacts of the same session, with the amount that has nowhere to go reported separately rather than quietly dropped.

Where the prices come from

Anthropic published API pricing, as documented in the claude-api reference bundled with Claude Code (skill version cached 2026-06-24). Cache multipliers from the prompt-caching documentation in the same bundle. Retrieved 2026-08-03. They live in pricing.json and are meant to be edited: list prices are not what every account pays, batch requests are half price, and partner platforms are billed separately. Cache multipliers used here: read ×0.1, five-minute write ×1.25, one-hour write ×2.0.

A dollar figure here is an estimate of list-price spend, not an invoice. It cannot see negotiated rates, batch discounts, or anything billed outside the API.
